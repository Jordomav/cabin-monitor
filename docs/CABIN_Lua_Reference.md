# CABIN Base Monitor — Lua Scripts Reference

All CC:Tweaked Lua scripts for the `cabin-base/minecraft/` folder. This document covers every script, its purpose, configuration, and how it fits into the wider system. Read alongside `CABIN_Base_Monitor_TRD.md`.

---

## Reference Documentation

Always check these before writing or modifying any Lua script. They are the source of truth for available APIs and peripherals.

**CC:Tweaked (ComputerCraft Redux)**
- Main docs: https://tweaked.cc
- HTTP API: https://tweaked.cc/module/http.html
- Peripheral API: https://tweaked.cc/module/peripheral.html
- Redstone API: https://tweaked.cc/module/redstone.html
- Rednet API: https://tweaked.cc/module/rednet.html
- GPS API: https://tweaked.cc/module/gps.html
- Turtle API: https://tweaked.cc/module/turtle.html
- Monitor peripheral: https://tweaked.cc/peripheral/monitor.html
- Speaker peripheral: https://tweaked.cc/peripheral/speaker.html
- textutils (JSON): https://tweaked.cc/module/textutils.html

**Create: Crafts and Additions (CC peripheral support)**
- GitHub: https://github.com/mrh-is/create-crafts-and-additions
- Peripheral list — check the mod's wiki or GitHub for exact peripheral type names and available methods for:
  - Stressometer (reads SU stress on a shaft)
  - Speedometer (reads RPM on a shaft)
  - Rotation Speed Controller
  - Fluid Tank
  - Basin

**Ender Storage (for ender chest item IDs)**
- Check REI in game for exact item IDs — mod ID may be `enderstorage:ender_chest`

**FTB Chunks (for force chunk loading)**
- Not scriptable via CC — configured via in-game map UI

## System Architecture — Lua Side

```
Farm computers (one per farm)
    → monitors local vault fill via peripheral
    → controls farm on/off via redstone output
    → listens for override commands from central via rednet
    → sends status reports to central via rednet every 5 seconds

Central computer
    → receives reports from all farm computers via rednet
    → aggregates into single state object
    → POSTs state to Node.js web server via HTTP every 2-3 seconds
    → GETs pending commands from web server via HTTP every 2-3 seconds
    → forwards commands to relevant farm computers via rednet
    → displays summary on attached monitor
```

## base_farm.lua

Shared module loaded by every farm script. Contains all common logic so individual farm scripts are just config + a require. This way updating common behavior means editing one file.

```lua
-- base_farm.lua
-- Shared logic for all farm computers
-- Load with: local farm = require("farms/base_farm")

local M = {}

function M.setup()
  -- Load config
  if not fs.exists("config.lua") then
    error("config.lua not found. Run installer.lua to set up this computer.")
  end
  dofile("config.lua")

  -- Wrap peripherals
  M.monitor = peripheral.wrap(MONITOR_SIDE)
  M.vault = peripheral.wrap(VAULT_SIDE)
  M.modem = peripheral.wrap(MODEM_SIDE)

  if not M.monitor then error("No monitor found on " .. MONITOR_SIDE) end
  if not M.vault then error("No vault found on " .. VAULT_SIDE) end
  if not M.modem then error("No modem found on " .. MODEM_SIDE) end

  rednet.open(MODEM_SIDE)
  return M
end

function M.getVaultFill()
  -- Works with Create vaults and standard chests/barrels
  local vaultType = peripheral.getType(VAULT_SIDE)

  if vaultType == "create:vault" then
    -- Create vault has different API
    local used = 0
    local capacity = 0
    local items = M.vault.list()
    for _, item in pairs(items) do
      used = used + item.count
    end
    -- Create vault capacity varies by size — try to get it
    if M.vault.getCapacity then
      capacity = M.vault.getCapacity()
    else
      capacity = 20480  -- default 2x4x2 vault estimate
    end
    return math.floor((used / capacity) * 100)
  else
    -- Standard chest/barrel
    local used = 0
    local items = M.vault.list()
    for _, item in pairs(items) do
      used = used + item.count
    end
    local max = M.vault.size() * 64
    return math.floor((used / max) * 100)
  end
end

function M.setFarmRunning(state)
  -- Inverted: redstone HIGH = farm off (kills power to shaft)
  redstone.setOutput(REDSTONE_SIDE, not state)
end

function M.isFarmRunning()
  return not redstone.getOutput(REDSTONE_SIDE)
end

function M.updateMonitor(fill, running, override)
  M.monitor.clear()
  M.monitor.setTextScale(0.5)
  M.monitor.setCursorPos(1, 1)

  -- Title
  M.monitor.setTextColor(colors.yellow)
  M.monitor.write(string.upper(FARM_NAME) .. " FARM")

  -- Divider
  M.monitor.setCursorPos(1, 2)
  M.monitor.setTextColor(colors.gray)
  M.monitor.write(string.rep("-", 16))

  -- Fill bar
  M.monitor.setCursorPos(1, 3)
  M.monitor.setTextColor(colors.white)
  M.monitor.write("Vault: " .. fill .. "%")

  M.monitor.setCursorPos(1, 4)
  local barLen = 16
  local filled = math.floor((fill / 100) * barLen)
  local bar = "[" .. string.rep("=", filled) .. string.rep("-", barLen - filled) .. "]"
  if fill > HIGH_THRESHOLD then
    M.monitor.setTextColor(colors.red)
  elseif fill > 60 then
    M.monitor.setTextColor(colors.yellow)
  else
    M.monitor.setTextColor(colors.green)
  end
  M.monitor.write(bar)

  -- Status
  M.monitor.setCursorPos(1, 6)
  if override then
    M.monitor.setTextColor(colors.orange)
    M.monitor.write("OVERRIDE")
  elseif running then
    M.monitor.setTextColor(colors.green)
    M.monitor.write("RUNNING")
  else
    M.monitor.setTextColor(colors.red)
    M.monitor.write("PAUSED " .. fill .. "%")
  end

  -- Computer ID
  M.monitor.setCursorPos(1, 8)
  M.monitor.setTextColor(colors.gray)
  M.monitor.write("ID: " .. os.getComputerID())
end

function M.sendReport(fill, running, override)
  rednet.send(CENTRAL_ID, {
    type = "farm_report",
    farm = FARM_NAME,
    fill = fill,
    running = running,
    override = override,
    timestamp = os.clock()
  })
end

function M.listenForCommands(override, override_state)
  -- Non-blocking check for incoming rednet messages
  local id, message = rednet.receive(0.1)  -- 0.1s timeout
  if id == CENTRAL_ID and type(message) == "table" then
    if message.command == "override_on" then
      override = true
      override_state = true
      M.setFarmRunning(true)
    elseif message.command == "override_off" then
      override = true
      override_state = false
      M.setFarmRunning(false)
    elseif message.command == "clear_override" then
      override = false
    elseif message.command == "ping" then
      rednet.send(CENTRAL_ID, { type = "pong", farm = FARM_NAME })
    end
  end
  return override, override_state
end

function M.run()
  local override = false
  local override_state = false

  while true do
    local fill = M.getVaultFill()
    local running = M.isFarmRunning()

    -- Local automatic control (only when not overridden)
    if not override then
      if fill >= HIGH_THRESHOLD and running then
        M.setFarmRunning(false)
        running = false
      elseif fill <= LOW_THRESHOLD and not running then
        M.setFarmRunning(true)
        running = true
      end
    end

    -- Update display and report
    M.updateMonitor(fill, running, override)
    M.sendReport(fill, running, override)

    -- Listen for commands
    override, override_state = M.listenForCommands(override, override_state)

    sleep(REPORT_INTERVAL)
  end
end

return M
```

## central.lua

The main aggregator and web server bridge. Runs on the central control computer in the control tower.

```lua
-- Central Control Computer
-- Aggregates farm reports, posts to web server, polls for commands

-- ─────────────────────────────────────────
-- CONFIGURATION
-- ─────────────────────────────────────────
local WEB_SERVER_URL = "http://your-droplet-ip:3000"
local WEB_API_KEY = "your-secret-key"
local MONITOR_SIDE = "top"
local MODEM_SIDE = "right"
local REPORT_INTERVAL = 3       -- seconds between web server posts
local REPORT_TIMEOUT = 15       -- seconds before farm marked offline

-- Farm priority tiers — must match dashboard FARM_PRIORITIES config
-- 1 = critical (never shut down)
-- 2 = high (shut down only if critical power)
-- 3 = medium (shut down on power warning)
-- 4 = low (first to go)
local FARM_PRIORITIES = {
  mechanism     = 1,
  chapter_1     = 1,
  chapter_2     = 1,
  chapter_3     = 1,
  chapter_4     = 1,
  chapter_5     = 1,
  iron          = 2,
  wood          = 2,
  andesite      = 2,
  brass         = 2,
  gold          = 3,
  copper        = 3,
  zinc          = 3,
  concrete      = 3,
  cobble        = 4,
  gravel        = 4,
  sand          = 4,
  granite       = 4,
}

-- Farm computer rednet IDs
-- Fill these in once you know each computer's ID
-- Find ID by running: print(os.getComputerID()) on each computer
local FARM_IDS = {
  wood          = 2,
  iron          = 3,
  andesite      = 4,
  cobble        = 5,
  gravel        = 6,
  sand          = 7,
  gold          = 8,
  copper        = 9,
  zinc          = 10,
  granite       = 11,
  concrete      = 12,
  brass         = 13,
  mechanism     = 14,
  chapter_1     = 15,
  chapter_2     = 16,
  chapter_3     = 17,
  chapter_4     = 18,
  chapter_5     = 19,
}

-- Reverse lookup: ID -> farm name
local ID_TO_FARM = {}
for farm, id in pairs(FARM_IDS) do
  ID_TO_FARM[id] = farm
end

-- ─────────────────────────────────────────
-- STATE
-- ─────────────────────────────────────────
local farmStatus = {}
local powerStatus = {
  generation = 0,
  consumption = 0,
  ratio = 0,
  state = "NORMAL"
}
local alerts = {}
local lastAlertTime = {}
local trainStatus = {}

-- ─────────────────────────────────────────
-- PERIPHERALS
-- ─────────────────────────────────────────
local monitor = peripheral.wrap(MONITOR_SIDE)
local modem = peripheral.wrap(MODEM_SIDE)
rednet.open(MODEM_SIDE)

-- Try to find Create power peripheral
-- Attach a stressometer to the central computer for real SU readings
local powerPeripheral = nil
for _, name in ipairs(peripheral.getNames()) do
  local pType = peripheral.getType(name)
  if pType == "create:stressometer" or pType == "create:speedometer" then
    powerPeripheral = peripheral.wrap(name)
    break
  end
end

-- ─────────────────────────────────────────
-- HELPERS
-- ─────────────────────────────────────────
local function addAlert(message, level)
  table.insert(alerts, 1, {
    message = message,
    level = level,
    time = os.clock()
  })
  while #alerts > 10 do
    table.remove(alerts)
  end
end

local function sendCommand(farmName, command)
  local id = FARM_IDS[farmName]
  if id then
    rednet.send(id, { command = command })
  end
end

-- ─────────────────────────────────────────
-- WEB SERVER COMMUNICATION
-- ─────────────────────────────────────────
local function postToWebServer()
  local payload = {
    timestamp = os.epoch("utc"),
    power = powerStatus,
    farms = farmStatus,
    alerts = alerts,
    trains = trainStatus
  }

  local ok, err = pcall(function()
    http.request({
      url = WEB_SERVER_URL .. "/update",
      method = "POST",
      headers = {
        ["Content-Type"] = "application/json",
        ["X-API-Key"] = WEB_API_KEY
      },
      body = textutils.serializeJSON(payload)
    })
  end)

  if not ok then
    addAlert("Web server unreachable", "WARN")
  end
end

local function checkForWebCommands()
  local ok, response = pcall(function()
    return http.get({
      url = WEB_SERVER_URL .. "/commands",
      headers = { ["X-API-Key"] = WEB_API_KEY }
    })
  end)

  if ok and response then
    local data = textutils.unserialiseJSON(response.readAll())
    response.close()

    if data and #data > 0 then
      for _, cmd in ipairs(data) do
        if cmd.type == "farm_override_on" and cmd.farm then
          sendCommand(cmd.farm, "override_on")
          addAlert(cmd.farm .. " force started by dashboard", "INFO")
        elseif cmd.type == "farm_override_off" and cmd.farm then
          sendCommand(cmd.farm, "override_off")
          addAlert(cmd.farm .. " force stopped by dashboard", "INFO")
        elseif cmd.type == "farm_clear_override" and cmd.farm then
          sendCommand(cmd.farm, "clear_override")
          addAlert(cmd.farm .. " override cleared by dashboard", "INFO")
        elseif cmd.type == "shutdown_all" then
          for farm, _ in pairs(FARM_IDS) do
            sendCommand(farm, "override_off")
          end
          addAlert("All farms shutdown by dashboard", "WARN")
        elseif cmd.type == "resume_all" then
          for farm, _ in pairs(FARM_IDS) do
            sendCommand(farm, "clear_override")
          end
          addAlert("All farms resumed by dashboard", "INFO")
        elseif cmd.type == "shutdown_priority" and cmd.tier then
          for farm, priority in pairs(FARM_PRIORITIES) do
            if priority >= cmd.tier then
              sendCommand(farm, "override_off")
            end
          end
          addAlert("Priority " .. cmd.tier .. "+ farms shutdown", "WARN")
        end
      end
    end
  end
end

-- ─────────────────────────────────────────
-- POWER MONITORING
-- ─────────────────────────────────────────
local function updatePowerStatus()
  if powerPeripheral then
    -- Read from Create stressometer peripheral
    -- Exact method names depend on Create: Crafts and Additions version
    -- Check https://github.com/mrh-is/create-crafts-and-additions for API
    local ok, stress = pcall(function()
      return powerPeripheral.getStress()
    end)
    local ok2, capacity = pcall(function()
      return powerPeripheral.getStressCapacity()
    end)

    if ok and ok2 then
      powerStatus.consumption = stress or 0
      powerStatus.generation = capacity or 0
    end
  end

  if powerStatus.generation > 0 then
    powerStatus.ratio = powerStatus.consumption / powerStatus.generation
  else
    powerStatus.ratio = 0
  end

  if powerStatus.ratio >= 0.90 then
    powerStatus.state = "CRITICAL"
  elseif powerStatus.ratio >= 0.75 then
    powerStatus.state = "WARNING"
  else
    powerStatus.state = "NORMAL"
  end
end

-- ─────────────────────────────────────────
-- FARM TIMEOUT DETECTION
-- ─────────────────────────────────────────
local function checkTimeouts()
  local now = os.clock()
  for farm, status in pairs(farmStatus) do
    if status.timestamp and (now - status.timestamp) > REPORT_TIMEOUT then
      if status.online then
        status.online = false
        addAlert(farm .. " farm offline!", "CRIT")
      end
    end
  end
end

-- ─────────────────────────────────────────
-- MONITOR DISPLAY
-- ─────────────────────────────────────────
local function updateDisplay()
  if not monitor then return end
  monitor.clear()
  monitor.setTextScale(0.5)

  -- Header
  monitor.setCursorPos(1, 1)
  monitor.setTextColor(colors.yellow)
  monitor.write("=== CENTRAL CONTROL ===")

  monitor.setCursorPos(1, 2)
  monitor.setTextColor(colors.gray)
  monitor.write(textutils.formatTime(os.time(), false))

  -- Power status
  monitor.setCursorPos(1, 4)
  monitor.setTextColor(colors.white)
  monitor.write("POWER: ")
  if powerStatus.state == "CRITICAL" then
    monitor.setTextColor(colors.red)
    monitor.write("!! CRITICAL !!")
  elseif powerStatus.state == "WARNING" then
    monitor.setTextColor(colors.orange)
    monitor.write("WARNING")
  else
    monitor.setTextColor(colors.green)
    monitor.write("NORMAL")
  end

  -- Farm statuses
  local y = 6
  monitor.setCursorPos(1, y)
  monitor.setTextColor(colors.yellow)
  monitor.write("FARMS")
  y = y + 1

  -- Sort by priority
  local sorted = {}
  for farm, _ in pairs(FARM_IDS) do
    table.insert(sorted, farm)
  end
  table.sort(sorted, function(a, b)
    local pa = FARM_PRIORITIES[a] or 99
    local pb = FARM_PRIORITIES[b] or 99
    if pa == pb then return a < b end
    return pa < pb
  end)

  for _, farm in ipairs(sorted) do
    local status = farmStatus[farm]
    monitor.setCursorPos(1, y)
    if not status or not status.online then
      monitor.setTextColor(colors.gray)
      monitor.write(farm:sub(1, 14) .. " OFFLINE")
    elseif status.override then
      monitor.setTextColor(colors.orange)
      monitor.write(farm:sub(1, 14) .. " OVERRIDE")
    elseif status.running then
      monitor.setTextColor(colors.green)
      monitor.write(farm:sub(1, 14) .. " " .. (status.fill or 0) .. "%")
    else
      monitor.setTextColor(colors.red)
      monitor.write(farm:sub(1, 14) .. " PAUSED")
    end
    y = y + 1
    if y > 50 then break end
  end

  -- Recent alerts
  y = y + 1
  monitor.setCursorPos(1, y)
  monitor.setTextColor(colors.yellow)
  monitor.write("ALERTS")
  y = y + 1

  for i = 1, math.min(3, #alerts) do
    monitor.setCursorPos(1, y)
    if alerts[i].level == "CRIT" then
      monitor.setTextColor(colors.red)
    elseif alerts[i].level == "WARN" then
      monitor.setTextColor(colors.orange)
    else
      monitor.setTextColor(colors.lightGray)
    end
    monitor.write(alerts[i].message:sub(1, 20))
    y = y + 1
  end
end

-- ─────────────────────────────────────────
-- REDNET LISTENER
-- ─────────────────────────────────────────
local function listenForFarmReports()
  while true do
    local id, message = rednet.receive()
    local farmName = ID_TO_FARM[id]

    if farmName and type(message) == "table" then
      if message.type == "farm_report" then
        farmStatus[farmName] = {
          farm = farmName,
          fill = message.fill,
          running = message.running,
          override = message.override,
          online = true,
          timestamp = os.clock()
        }
      elseif message.type == "pong" then
        if farmStatus[farmName] then
          farmStatus[farmName].online = true
          farmStatus[farmName].timestamp = os.clock()
        end
      end
    end
  end
end

-- ─────────────────────────────────────────
-- MAIN LOOP
-- ─────────────────────────────────────────
local function mainLoop()
  addAlert("Central control started", "INFO")

  -- Ping all farms on startup
  for farm, id in pairs(FARM_IDS) do
    rednet.send(id, { command = "ping" })
  end

  while true do
    checkTimeouts()
    updatePowerStatus()
    postToWebServer()
    checkForWebCommands()
    updateDisplay()
    sleep(REPORT_INTERVAL)
  end
end

-- Run listener and main loop in parallel
parallel.waitForAll(mainLoop, listenForFarmReports)
```

## installer.lua

Interactive setup script. Run on any new computer to configure and deploy the correct script automatically.

```lua
-- CABIN Base Monitor Installer
-- Run with: lua installer.lua

local GITHUB_USER = "yourusername"
local GITHUB_REPO = "cabin-base"
local GITHUB_BRANCH = "main"
local BASE_URL = "https://raw.githubusercontent.com/" ..
                 GITHUB_USER .. "/" ..
                 GITHUB_REPO .. "/" ..
                 GITHUB_BRANCH .. "/minecraft/"

local FARM_SCRIPTS = {
  "wood", "iron", "andesite", "cobble", "gravel", "sand",
  "gold", "copper", "zinc", "granite", "concrete", "brass",
  "mechanism", "chapter_1", "chapter_2", "chapter_3",
  "chapter_4", "chapter_5"
}

local function clear()
  term.clear()
  term.setCursorPos(1, 1)
end

local function printColor(text, color)
  term.setTextColor(color or colors.white)
  print(text)
  term.setTextColor(colors.white)
end

local function download(url, path)
  local response = http.get(url)
  if not response then
    return false, "Failed to download " .. url
  end
  local content = response.readAll()
  response.close()
  local file = fs.open(path, "w")
  file.write(content)
  file.close()
  return true
end

local function downloadScript(scriptType)
  local url
  if scriptType == "central" then
    url = BASE_URL .. "central.lua"
  else
    -- Download base_farm first
    printColor("Downloading base_farm module...", colors.gray)
    local ok, err = download(BASE_URL .. "farms/base_farm.lua", "farms/base_farm.lua")
    if not ok then return false, err end
    url = BASE_URL .. "farms/" .. scriptType .. ".lua"
  end

  printColor("Downloading " .. scriptType .. " script...", colors.gray)
  local ok, err = download(url, "startup.lua")
  if not ok then return false, err end
  return true
end

local function askConfig()
  local config = {}

  printColor("\nEnter Central Computer ID:", colors.white)
  printColor("(run print(os.getComputerID()) on central to find it)", colors.gray)
  term.write("> ")
```

### universal_farm.lua

Replaces all individual farm scripts. Every farm computer runs this single script. It fetches farms.json from GitHub, finds its own config by computer ID, and runs.

```lua
-- universal_farm.lua
-- Single script for every farm computer in the base
-- Fetches farms.json from GitHub to find its own configuration
-- No local config.lua needed

local GITHUB_RAW = "https://raw.githubusercontent.com/yourusername/cabin-base/main/minecraft/"
local FARMS_JSON_URL = GITHUB_RAW .. "farms.json"
local CONFIG_CACHE = "farms_cache.json"  -- local cache in case GitHub unreachable

-- ─────────────────────────────────────────
-- CONFIG LOADING
-- ─────────────────────────────────────────
local function fetchFromGitHub()
  local ok, response = pcall(function()
    return http.get(FARMS_JSON_URL)
  end)

  if ok and response then
    local content = response.readAll()
    response.close()

    -- Cache to disk for offline fallback
    local file = fs.open(CONFIG_CACHE, "w")
    file.write(content)
    file.close()

    return textutils.unserialiseJSON(content)
  end
  return nil
end

local function loadFromCache()
  if fs.exists(CONFIG_CACHE) then
    local file = fs.open(CONFIG_CACHE, "r")
    local content = file.readAll()
    file.close()
    return textutils.unserialiseJSON(content)
  end
  return nil
end

local function loadFarmsConfig()
  -- Try GitHub first
  local data = fetchFromGitHub()
  if data then return data end

  -- Fall back to cache
  print("GitHub unreachable, using cached config...")
  data = loadFromCache()
  if data then return data end

  error("No config available. Check internet connection and try again.")
end

local function findMyConfig(farmsData)
  local myId = os.getComputerID()
  for _, farm in ipairs(farmsData.farms) do
    if farm.computer_id == myId then
      return farm
    end
  end
  return nil
end

-- ─────────────────────────────────────────
-- SETUP
-- ─────────────────────────────────────────
print("Loading farm config from GitHub...")
local farmsData = loadFarmsConfig()
local config = findMyConfig(farmsData)

if not config then
  print("ERROR: This computer (ID " .. os.getComputerID() .. ") not found in farms.json")
  print("Add this computer ID to farms.json and push to GitHub")
  print("Then reboot this computer")
  return
end

print("Found config for: " .. config.label)

-- Build central ID lookup from farms.json
-- Central is always the computer running central.lua
-- Its ID needs to be stored somewhere — add it to farms.json root level
local CENTRAL_ID = farmsData.central_computer_id or 1

-- Wrap peripherals from config
local monitor = peripheral.wrap(config.monitor_side)
local vault = peripheral.wrap(config.vault_side)
local modem = peripheral.wrap(config.modem_side)

if not monitor then error("No monitor on " .. config.monitor_side) end
if not vault then error("No vault on " .. config.vault_side) end
if not modem then error("No modem on " .. config.modem_side) end

rednet.open(config.modem_side)

-- ─────────────────────────────────────────
-- VAULT READING
-- ─────────────────────────────────────────
local function getVaultFill()
  local vaultType = peripheral.getType(config.vault_side)
  local used = 0
  local capacity = 0

  if vaultType == "create:vault" then
    local items = vault.list()
    for _, item in pairs(items) do
      used = used + item.count
    end
    capacity = vault.getCapacity and vault.getCapacity() or 20480
  else
    local items = vault.list()
    for _, item in pairs(items) do
      used = used + item.count
    end
    capacity = vault.size() * 64
  end

  if capacity == 0 then return 0 end
  return math.floor((used / capacity) * 100)
end

-- ─────────────────────────────────────────
-- FARM CONTROL
-- ─────────────────────────────────────────
local function setFarmRunning(state)
  redstone.setOutput(config.redstone_side, not state)
end

local function isFarmRunning()
  return not redstone.getOutput(config.redstone_side)
end

-- ─────────────────────────────────────────
-- MONITOR DISPLAY
-- ─────────────────────────────────────────
local function updateMonitor(fill, running, override)
  monitor.clear()
  monitor.setTextScale(0.5)

  monitor.setCursorPos(1, 1)
  monitor.setTextColor(colors.yellow)
  monitor.write(string.upper(config.label))

  monitor.setCursorPos(1, 2)
  monitor.setTextColor(colors.gray)
  monitor.write("ID: " .. os.getComputerID() .. " | " .. config.wing)

  monitor.setCursorPos(1, 3)
  monitor.setTextColor(colors.gray)
  monitor.write(string.rep("-", 20))

  monitor.setCursorPos(1, 4)
  monitor.setTextColor(colors.white)
  monitor.write("Vault: " .. fill .. "%")

  monitor.setCursorPos(1, 5)
  local barLen = 18
  local filled = math.floor((fill / 100) * barLen)
  if fill > config.high_threshold then
    monitor.setTextColor(colors.red)
  elseif fill > 60 then
    monitor.setTextColor(colors.yellow)
  else
    monitor.setTextColor(colors.green)
  end
  monitor.write("[" .. string.rep("=", filled) .. string.rep("-", barLen - filled) .. "]")

  monitor.setCursorPos(1, 7)
  if override then
    monitor.setTextColor(colors.orange)
    monitor.write("OVERRIDE")
  elseif running then
    monitor.setTextColor(colors.green)
    monitor.write("RUNNING")
  else
    monitor.setTextColor(colors.red)
    monitor.write("PAUSED")
  end

  monitor.setCursorPos(1, 8)
  monitor.setTextColor(colors.gray)
  monitor.write("Pri: " .. config.priority .. " | Thr: " .. config.low_threshold .. "-" .. config.high_threshold .. "%")
end

-- ─────────────────────────────────────────
-- REDNET COMMUNICATION
-- ─────────────────────────────────────────
local function sendReport(fill, running, override)
  rednet.send(CENTRAL_ID, {
    type = "farm_report",
    farm = config.id,
    label = config.label,
    wing = config.wing,
    priority = config.priority,
    fill = fill,
    running = running,
    override = override,
    timestamp = os.clock()
  })
end

-- ─────────────────────────────────────────
-- MAIN LOOP
-- ─────────────────────────────────────────
local override = false
local override_state = false

local function listenForCommands()
  while true do
    local id, message = rednet.receive()
    if id == CENTRAL_ID and type(message) == "table" then
      if message.command == "override_on" then
        override = true
        override_state = true
        setFarmRunning(true)
      elseif message.command == "override_off" then
        override = true
        override_state = false
        setFarmRunning(false)
      elseif message.command == "clear_override" then
        override = false
      elseif message.command == "ping" then
        rednet.send(CENTRAL_ID, { type = "pong", farm = config.id })
      end
    end
  end
end

local function mainLoop()
  print("Running as: " .. config.label)

  while true do
    local fill = getVaultFill()
    local running = isFarmRunning()

    -- Local automatic control
    if not override then
      if fill >= config.high_threshold and running then
        setFarmRunning(false)
        running = false
      elseif fill <= config.low_threshold and not running then
        setFarmRunning(true)
        running = true
      end
    end

    updateMonitor(fill, running, override)
    sendReport(fill, running, override)

    sleep(config.report_interval or 5)
  end
end

parallel.waitForAll(mainLoop, listenForCommands)
```

## Notes for Claude Code

- All farm scripts are identical in behavior — only config.lua differs per machine. The shared logic lives in `base_farm.lua` to avoid duplicating code across 18+ files.
- `textutils.serializeJSON` and `textutils.unserialiseJSON` are the correct CC:Tweaked function names — verify these exist in the CABIN bundled version before using.
- Rednet requires a wireless modem to be attached and opened before use — always call `rednet.open(MODEM_SIDE)` on startup.
- HTTP requests in CC:Tweaked are asynchronous by default — use `http.get()` for synchronous blocking requests, `http.request()` for async. The scripts above use blocking requests for simplicity.
- Create vault peripheral type is `"create:vault"` — verify this is correct for CABIN's Create version.
- Create stressometer peripheral type for Crafts and Additions may differ — check https://github.com/mrh-is/create-crafts-and-additions for exact peripheral type name and available methods.
- The `parallel.waitForAll` pattern in central.lua runs both the main loop and the rednet listener concurrently — this is the correct CC:Tweaked way to handle multiple concurrent tasks.
- GPS requires 4 GPS host computers set up in the world before `gps.locate()` returns coordinates. If GPS is not set up `gps.locate()` returns nil — always handle this gracefully.
- Turtle fuel: each forward/back/up/down movement costs 1 fuel. Digging costs 0 fuel. Coal = 80 fuel, charcoal = 80 fuel, coal block = 800 fuel.
